# High Seas

High Seas is a NeoForge mod that adds a physically simulated flooding and buoyancy system for large ships built with Create Aeronautics.

Instead of using simplified "boat physics", the mod simulates:

- Real buoyancy based on displaced water volume
- Material density
- Internal watertight compartments
- Progressive flooding
- Floodwater weight
- Pressure-driven water propagation between compartments
- Ship trim and list during flooding

The system is designed primarily for large, realistic ships rather than vanilla boats.

## Features

- Physical buoyancy simulation
- Material density support
- Internal compartment flooding
- Progressive loss of displacement as compartments flood
- Dynamic stability changes
- Pressure-based flooding
- Flood weight affecting the ship's center of mass

## Requirements

This mod requires the following mods:

- Create
- Create Aeronautics
- Sable

All required dependencies must be installed.

## Compatibility

- Minecraft 1.21.1
- NeoForge

## Installation

1. Install NeoForge.
2. Install the required dependencies:
   - Create
   - Create Aeronautics
   - Sable
3. Place `highseas-<version>.jar` into your `mods` folder.
4. Launch the game.
